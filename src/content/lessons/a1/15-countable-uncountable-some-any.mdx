## Can you count it?

<FormTable caption="Countable and uncountable">

| | Countable | Uncountable |
|---|---|---|
| Examples | egg, apple, chair, book, friend | milk, water, rice, money, bread, sugar |
| a / an? | **an** egg | no: *~~a milk~~* |
| plural -s? | two egg**s** | no: *~~milks~~* |
| some (+) | some egg**s** | some milk |
| any (− ?) | any eggs? | any milk? |
| How…? | How **many** eggs? | How **much** milk? |

</FormTable>

## some or any?

- **some** in **positive** sentences: *I have some friends in Canada.*
- **any** in **negative** sentences and **questions**: *I don't have any friends there. Do you have any friends there?*

## How much? How many? A lot of

- **How many** + countable plural: *How many children do they have?*
- **How much** + uncountable: *How much sugar do you want?*
- **a lot of** + both: *a lot of friends, a lot of time.*

<Persian>

**قابل‌شمارش و غیرقابل‌شمارش:** بعضی اسم‌ها را می‌شمریم (an egg، two eggs) و بعضی را نه (milk، water، rice، money، bread).

- اسم غیرقابل‌شمارش a یا an نمی‌گیرد و جمع (s) هم نمی‌شود.
- **نکته برای فارسی‌زبان‌ها:** ما می‌گوییم «یک نان» یا «دو تا نان»، اما bread در انگلیسی غیرقابل‌شمارش است: some bread یا a loaf of bread. همین‌طور money هیچ‌وقت moneys نمی‌شود.

**some و any:** در جمله‌ی مثبت **some** (کمی / چندتا)، در جمله‌ی منفی و سؤالی **any**.

**How much / How many:** How many برای چیزهای شمردنی (چند تا؟) و How much برای غیرشمردنی (چقدر؟). a lot of (زیاد) برای هر دو.

</Persian>

<MemoryHook title="The two-test">
