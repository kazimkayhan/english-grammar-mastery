## Something exists

To say that something exists, or is in a place, English starts with **there**:

<FormTable caption="there is / there are">

| | One (or uncountable) | More than one |
|---|---|---|
| **+** | There **is** (There's) a bank. | There **are** two banks. |
| **−** | There **isn't** a bank. | There **aren't** any banks. |
| **?** | **Is there** a bank? | **Are there** any banks? |
| **Short answers** | Yes, there **is**. / No, there **isn't**. | Yes, there **are**. / No, there **aren't**. |

</FormTable>

<Example context="home" fa="یک آشپزخانه‌ی بزرگ هست و دو اتاق خواب."><mark>There's</mark> a big kitchen, and <mark>there are</mark> two bedrooms.</Example>
<Example context="travel" fa="ببخشید، این نزدیکی داروخانه هست؟">Excuse me, <mark>is there</mark> a pharmacy near here?</Example>
<Example context="shopping" fa="در یخچال تخم‌مرغ هست، ولی شیر نیست.">There are <mark>some</mark> eggs in the fridge, but there <mark>isn't any</mark> milk.</Example>

## a, some, any

- **There's a** + one countable thing: *There's a cat in the garden.*
- **There are some** + plural, **There's some** + uncountable: *There are some apples. There's some bread.*
- **any** in negatives and questions: *There aren't any apples. Is there any bread?*

<Persian>

**وجود داشتن:** در فارسی می‌گوییم «در شهرم یک پارک **هست**» و فعل آخر می‌آید. در انگلیسی جمله با **there** شروع می‌شود:

- یکی (یا غیرقابل‌شمارش) ← There **is** (There's): There's a park in my city.
- چندتا ← There **are**: There are two parks.

**منفی:** There isn't a… / There aren't any…
**سؤال:** Is there a…? / Are there any…?

**اشتباه رایج:** «In my city is a park» غلط است؛ بگویید There is a park in my city. (درباره‌ی some و any در درس بعد بیشتر یاد می‌گیرید.)

</Persian>
